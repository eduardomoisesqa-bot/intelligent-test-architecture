# Test Automation Request

## Feature
Login

## Base URL
https://front.serverest.dev/

## Business Goal
Validar que um usuário cadastrado consegue acessar o sistema com sucesso.

## Acceptance Criteria
- Usuário válido deve conseguir realizar login
- Usuário inválido deve visualizar mensagem de erro
- Campos obrigatórios devem ser validados

## Target Layer
E2E Web

## Expected Output
- BDD scenarios
- Suggested selectors
- Page Object structure
- Flow structure
- Test class structure
